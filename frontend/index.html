LingoPDF Guide & Manual

Document Layout Parsing Options

LingoPDF uses advanced layout detection to separate paragraphs, equations, headers, and tables, ensuring standard linear reading before translating. Choose your backend engine:

Option A: Datalab API (Recommended for Cloud Setup)

  1. Sign up at datalab.to.
  2. Retrieve your **API Key** from your dashboard.
  3. Input it under Configuration > Datalab API Key.
  4. This utilizes cloud high-accuracy models without taxing your machine.

Option B: Marker Local Installation (Requires Local GPU/CPU)

If you prefer running layouts offline without external API keys:

  1. Install Marker in your terminal: 
    pip install marker-pdf
  2. Ensure the command marker_single is available in your system path.
  3. The local model will download weights automatically on first execution and process files locally.

Option C: PyMuPDF Fallback (Instant, Zero Setup)

If neither Datalab nor local Marker is set up, PyMuPDF runs locally to parse text positioning and rebuild layouts instantly. Works out of the box!

Configuring Translation LLMs

All translations and chats are powered by Large Language Models. Set up your preferred host:

Option A: Ollama (Local & Free)

For running completely offline local translations:

  1. Download and install Ollama on your machine.
  2. Pull your desired model from your terminal: 
    ollama pull llama3
  3. LingoPDF automatically queries and loads all your installed Ollama models in the selection dropdown.

Option B: Standard Cloud APIs (OpenAI, Gemini, Claude, DeepSeek)

For high-accuracy cloud translation, connect using standard developer keys:

  1. Select your provider (e.g. Google Gemini, OpenAI, Anthropic, or DeepSeek).
  2. Input your active API Key under configuration.
  3. Click Test Connection to verify, then click the **Refresh** icon to load all available models online.

Option C: Custom LLM Providers (vLLM, Groq, OpenRouter, LM Studio)

To connect to local clusters, inference backends, or alternative servers:

  1. Click the Plus (+) button in the settings panel.
  2. Provide a provider name and base URL (e.g., OpenRouter or Groq).
  3. Select the custom provider, insert its credentials, and fetch its active models.

SOCKS5 & HTTP Proxy Configurations

To route cloud API calls and HuggingFace local weights downloads through proxy networks:

1. Enable Proxy Routing

Toggle the Enable Proxy option in the settings. This ensures all HTTP/HTTPS and SOCKS requests are safely tunneled.

2. Supported Formats

By default, LingoPDF connects to a SOCKS5 proxy running on 127.0.0.1:1080. Provide URLs in the following structures:

  • SOCKS5: socks5://127.0.0.1:1080 (or 127.0.0.1:1080 which defaults to SOCKS5)
  • SOCKS5 with Auth: socks5://username:password@127.0.0.1:1080
  • HTTP/HTTPS: http://127.0.0.1:8080

3. Local Bypass

Internal network endpoints (such as your local Ollama server running on http://127.0.0.1:11434) are automatically detected and bypass proxy configurations to prevent network conflicts.
